# ZDM ChatCart: improvement pack

This folder turns the design review into build tasks.

- `PRIORITIES.md`: the build order, as a checklist. Start here.
- `sections/NN-name.md`: one file per CRM section (15). Purpose, what works today, how it should work, what the next screen contains, what's missing with priority and effort, and the code files to start from.
- `sections/11b-shop-front.md`: the customer-facing shop page redesign (home, product sheet, checkout, themes).
- `journeys.md`: the five customer stages and the gaps in how customers move between them.
- `images/`: PNGs of every design board (section blueprints and journey maps). Open the matching image when working on a section.
- `boards-html/`: the HTML source of those boards, if you want exact wording or layout.

Numbers in each section's "What's missing" table match the blue pins on its image.
